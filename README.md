# Soup Ratio Bistro

A tiny browser game where you buy frozen corn, peas, and carrots, mix them into soup, and serve it to customers who ask for different vegetable ratios.

## How to play

1. Open `index.html` in a browser, or run a local web server:
   - `python3 -m http.server 8000`
   - then visit `http://localhost:8000`
2. Buy produce from the market.
3. Add it to the soup pot with the plus and minus controls.
4. Serve the soup when the customer order matches the ratio they want.
5. Earn cash and reputation for successful soups.

## Goal

Match each customer’s requested ratio as closely as possible. The closer your soup matches their target mix, the more likely you are to win the order and earn money.
